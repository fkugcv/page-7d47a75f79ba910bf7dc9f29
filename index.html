Architecture

核心调度指标

多重接入隧道

支持按用户身份分配独立订阅哈希，通过动态端点调度隔离并发流量，避免单点阻断扩散至全域集群。

配额计量模式

系统按实际双向通道出入流量合并计算。周期重置日以账单生成时间戳为准，无多余隐藏扣除项目。

跨平台分发兼容

输出格式标准遵循公有核心配置文件规范，支持直连解析，不锁定特定专有二进制运行环境。

Deployment

标准初始化流程

01. 生成配置

获取订阅凭证

在用户控制台选定服务层级并确认订单后，系统将下发唯一的订阅 URL 及专属配置文件。

02. 导入核心

载入本地客户端

将订阅链接复制至经过验证的通用网络代理内核工具，触发远端节点清单同步解析。

03. 策略指定

分流规则编排

依据业务需求配置分流列表，指定直连网段与代理路由，避免内网服务受到流量穿透影响。

04. 连通校验

链路延迟探针

通过控制台内置测试脚本验证 TCP 与 UDP 端口响应状态，确立主备用链路切换顺序。

Endpoints

终端支持说明

FreeGate 不提供捆绑式专有第三方可执行程序。用户可通过各平台成熟的开源网络核心程序（如 Clash、Sing-box、Surge、v2ray 等标准通用内核）加载订阅信息。

各操作系统环境均采用标准化配置文件结构下发，无需安装额外驱动即可直接依托本地 TUN/TAP 虚拟网卡设备运行。

  • macOS / iOS 支持通用配置文件直接导入，兼容系统 Network Extension
  • Windows 10 / 11 通过系统服务驱动接管本地流量，需授予管理员网络权限
  • Linux (amd64 / arm64) 支持 systemd 守护进程运行模式及无头服务器终端调用
  • OpenWrt / 路由系统 支持软路由旁路部署模式，实现局域网设备无感透明分流
Troubleshooting

常见问题解答

多设备在线数量是如何判定的？

系统网关在传输层动态维护客户端公网出口 IP 与哈希映射表。若同一时刻发起握手的独立公网网络环境超出套餐上限，后发起的连接请求将被限流或返回连接超时错误。

流量配额用尽后的处理逻辑是什么？

当月统计周期内已用传输量达到账单配额后，节点权限将被临时挂起，数据连接返回阻断状态。用户可选择追加流量附加包或等待下一个账单周期的自动重置。

团队版定制路由具体支持哪些范畴？

团队版允许为特定组织实体划分独立出口池，并支持结合企业固定办公公网 IP 建立安全访问白名单，以保障特定企业级私有云或协同平台的访问合规。

如何排查订阅信息更新失败的情况？

请首先检查本机系统时间是否已通过 NTP 服务校准同步，时差超过 60 秒可能导致 TLS 握手失败；其次确认本地网络环境是否能正常解析订阅接口的 DNS 地址。
